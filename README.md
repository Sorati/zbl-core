#### Что бы создать свой собственный набор нужно:

1. Создать артефакты, если они ещё не созднанны
2. Создать предмет типа "**Особенность**"
3. В созданной особенности перейти во вкладку "**Подробности**"
4. В расскрывающимся списке поля "**Тип**", выбрать "**Особенность набора артефактов**"
5. Перетянуть нужные артефакты в появившееся поле
6. После этого, когда у персонажа будут перечисленные артефакты из этого поля, особенность будет автоматически появлять

> Есть у предметов не будет требования к **настройке**, особенность будет появляться сразу же. При наличиии требования к **настройке**, особенность сборки появится только при **настройке** персонажа на все предметы из этого набора.
